HTML. Створення списків

Три види списків у HTML та їх вкладення

Списки допомагають впорядкувати інформацію на вебсторінці: меню навігації, кроки інструкції, словник термінів або багаторівневий зміст.

Вид 1 • Маркований

Маркований список: <ul> та <li>

Використовується, коли порядок пунктів не є принциповим (наприклад, перелік компонентів ПК або товарів). Кожен пункт огортається в парний тег <li>...</li>.

Атрибут type (або CSS list-style-type) змінює форму маркера: disc (зафарбоване коло — за замовчуванням), circle (порожнє коло), square (квадрат). 

<ul type="square">
  <li>Процесор</li>
  <li>Оперативна пам’ять</li>
</ul>
Вид 2 • Нумерований

Нумерований список: <ol> та <li>

Застосовується для покрокових алгоритмів, рейтингів і правил, де важлива послідовність.

Атрибути <ol>:
• type: "1" (цифри), "A" (великі латинські), "a" (малі латинські), "I" (великі римські), "i" (малі римські).
• start="5" — задає початкове число нумерації.
• reversed — зворотна нумерація (від більшого до меншого). 

<ol type="I" start="3">
  <li>Розділ третій</li>
  <li>Розділ четвертий</li>
</ol>
Вид 3 • Список означень

Список означень: <dl>, <dt>, <dd>

Ідеальний для словників термінів, глосаріїв та питань-відповідей:

• <dl> (Description List) — контейнер усього списку означень.
• <dt> (Description Term) — назва терміна.
• <dd> (Description Details) — тлумачення терміна (браузер автоматично додає відступ зліва). 

<dl>
  <dt>HTML</dt>
  <dd>Мова розмітки гіпертексту.</dd>
</dl>
Структура • Багаторівневі

Вкладені списки (Багаторівневі)

Будь-який список (<ul> або <ol>) можна вкласти всередину іншого, щоб створити підпункти.

Головне правило валідного HTML: вкладений список розташовується усередині тегу <li>...</li> батьківського пункту, а не між двома <li>! 

<ul>
  <li>Фрукти
    <ol>
      <li>Яблуко</li>
      <li>Груша</li>
    </ol>
  </li>
</ul>
